# 🔮 Quantum Lottery Analysis V2

**Κβαντική ανάλυση EuroJackpot — από το 2012 μέχρι σήμερα**

Ένα πλήρες, αυτοματοποιημένο ερευνητικό σύστημα που αντιστοιχίζει την κλήρωση
του EuroJackpot σε **κβαντικό σύστημα** και παράγει προβλέψεις δύο σκελετών,
με αυτόματο κύκλωμα: **λήψη κλήρωσης → καταχώρηση → πρόβλεψη → σύγκριση με
την προηγούμενη πρόβλεψη → email → μόνιμο log**.

## ⚠️ Νομική δήλωση / Σκοπός

Οι κληρώσεις του EuroJackpot είναι **ανεξάρτητα τυχαία συμβάντα**. Κανένα
μοντέλο — κβαντικό, κλασικό ή στατιστικό — **δεν αυξάνει τις πιθανότητες
νίκης**. Το έργο είναι αυστηρά **εκπαιδευτικό, ερευνητικό και ψυχαγωγικό**:
μελετά το ιστορικό (2012→σήμερα), τεκμηριώνει μεθοδολογία, καταγράφει κάθε
πρόβλεψη και κάθε αποτέλεσμα, ώστε να υπάρχει ειλικρινές μέτρο επίδοσης σε
βάθος χρόνου. Παίξε υπεύθυνα. Δεν σχετίζεται με Eurojackpot, ΟΠΑΠ ή οποιονδήποτε
επίσημο οργανισμό.

## 🧠 Τι κάνει το σύστημα (σύνοψη)

| Βήμα | Τι γίνεται |
|---|---|
| 1 | Τραβάει αυτόματα κάθε νέα κλήρωση (2 πηγές + τοπικό CSV) |
| 2 | Την καταχωρεί στο ιστορικό `data/eurojackpot_history.csv` |
| 3 | Χτίζει κβαντική κατάσταση \|ψ⟩ από **1004 κληρώσεις** (2012→σήμερα) |
| 4 | Σαρώνει **και τα 139.838.160 σύμπαντα** (C(50,5)·C(12,2)) |
| 5 | Εκδίδει **Σκελετό Α (5+2)**, 2 εναλλακτικά κλαδιά, **Σκελετό Β (3+1)**, πίνακα top-10 και κλασική πρόβλεψη σύγκρισης |
| 6 | Συγκρίνει την προηγούμενη πρόβλεψη με την πραγματική κλήρωση (12 κατηγορίες βραβείων) |
| 7 | Στέλνει όμορφο HTML **email** (Gmail) και αποθηκεύει αναφορά `reports/` |
| 8 | Καταγράφει **τα πάντα** στο `logs/quantum.log` και `reports/predictions_history.jsonl` |

## 🎫 Οι δύο σκελετοί

- **Σκελετός Α — «Πλήρες Σύμπαν» (5 κύριοι + 2 τζόκερ):** το κλαδί σύμπαντος
  με τη μέγιστη βαρύτητα μετά από σάρωση και των 139.838.160 κλαδιών.
- **Σκελετός Β — «Κατάρρευση Παρατήρησης» (3 κύριοι + 1 τζόκερ):** η
  μερική μέτρηση — τα 3 νούμερα με τη μέγιστη κοινή κβαντική βαρύτητα.

## ⚛️ Οι κβαντικοί νόμοι που εφαρμόζονται (περίληψη)

1. **Χώρος Hilbert** — 50 ορθοκανονικές βάσεις |1⟩…|50⟩ + 12 βάσεις τζόκερ.
2. **Υπέρθεση** — πριν από κάθε κλήρωση όλοι οι συνδυασμοί «υπάρχουν ταυτόχρονα».
3. **Κύμα-σωματίδιο & διπλή σχισμή** — κάθε αριθμός έχει σωματιδιακή πυκνότητα
   και κυματική φάση· η συνάντηση δύο αριθμών προσθέτει πλάσεις με όρο
   αλληλεπίδρασης (ενισχυτική/καταστροφική συμβολή).
4. **Διεμπλοκή** — μήτρα συ-εμφανίσεων ζευγών (z-scores έναντι τύχης).
5. **Κβαντική διόδευση (tunneling)** — υπερ-αλυχισμένοι αριθμοί «διαπερνούν»
   το φράγμα απουσίας με σμικρή ώθηση.
6. **Ερμηνεία πολλαπλών σύμπαντων** — επιλέγεται το κλαδί μέγιστης βαρύτητας
   για **το δικό μας σύμπαν**.

## 🚀 Εγκατάσταση (Linux / Raspberry Pi) — 4 βήματα

```bash
# 1) Αντίγραψε τον φάκελο όπου θέλεις, π.χ.:
mv Quantum-Lottery-Analysis-V2 ~/quantum_lottery && cd ~/quantum_lottery

# 2) Εξαρτήσεις:
pip3 install -r requirements.txt

# 3) Email: αντίγραψε το .env.example → .env και συμπλήρωσέ το
cp .env.example .env && nano .env

# 4) Δοκιμή + αυτόματο πρόγραμμα (cron, Τρίτη & Παρασκευή 22:30):
python3 quantum_lottery.py test-email
bash setup_cron.sh
```

Αναλυτικές οδηγίες (Gmail App Password, cron, αντιμετώπιση προβλημάτων):
**INSTALL_GUIDE_LINUX.md**

## 📟 Εντολές

| Εντολή | Τι κάνει |
|---|---|
| `python3 quantum_lottery.py fetch` | Ενημερώνει το ιστορικό από τις πηγές |
| `python3 quantum_lottery.py predict` | Νέα πρόβλεψη για την επόμενη κλήρωση (+email) |
| `python3 quantum_lottery.py predict --no-email` | Πρόβλεψη χωρίς αποστολή email |
| `python3 quantum_lottery.py compare` | Σύγκριση εκκρεμών προβλέψεων με την τελευταία κλήρωση |
| `python3 quantum_lottery.py auto` | Ολόκληρο κύκλωμα για cron: fetch→compare→predict→email |
| `python3 quantum_lottery.py backtest` | Walk-forward αξιολόγηση σε όλο το ιστορικό (~15′) |
| `python3 quantum_lottery.py report` | Συσσωρευμένα στατιστικά επιτυχιών |
| `python3 quantum_lottery.py status` | Σύντομη εικόνα κατάστασης |
| `python3 quantum_lottery.py test-email` | Δοκιμή της σύνδεσης Gmail |
